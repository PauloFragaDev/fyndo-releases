## ✨ Características principales

- 📊 **Gestión financiera local-first**  
  Controla tus movimientos, categorías e ingresos sin enviar datos a la nube.

- 🧩 **Sistema modular**  
  Pensado para crecer: hábitos, knowledge base, tareas y más.

- 🔐 **Privacidad total**  
  Tus datos se almacenan únicamente en tu dispositivo.

- ⚡ **Rendimiento extremo** gracias a Tauri  
  Tamaño pequeño, uso mínimo de RAM y arranque instantáneo.

- 🎨 **Interfaz moderna y minimalista**  
  Diseño ultra-limpio inspirado en Notion, Linear y Raycast.
